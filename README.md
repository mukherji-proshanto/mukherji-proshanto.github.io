# mukherji-proshanto.github.io

Interactive applets for math courses at The Cambridge School of Weston, served by
GitHub Pages at <https://mukherji-proshanto.github.io/>.

Each applet is one self-contained HTML file — inline CSS and JS, no build step, no
external runtime dependencies — so it opens from a link with no sign-in, and works
just as well opened straight off disk.

| Applet | Course, unit | URL |
| --- | --- | --- |
| Roots Ring | Analytic Geometry, Unit 2 (nth roots) | `/roots-ring/` |
| Rows and Columns in Motion | Linear Algebra (Ax = b by rows and by columns) | `/rows-and-columns/` |

## Notation

Polar form in the Analytic Geometry tools is written `r cis θ`, and as the ordered pair `(r, θ)`.
Moduli are shown as exact radicals where an exact form exists. Euler's form is
deliberately absent: the Analytic Geometry course does not cover it.
